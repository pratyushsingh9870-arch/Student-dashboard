Student Performance Dashboard (Power BI)

##  Project Overview
This project is a data visualization dashboard created using Power BI to analyze student performance across different subjects. It provides insights into subject-wise marks, pass/fail distribution, and individual student performance.

---

## Objectives
- To visualize student marks in different subjects
- To analyze pass and fail distribution
- To provide interactive filtering using slicers
- To demonstrate basic data visualization techniques

---

## Tools & Technologies
- Power BI Desktop
- Microsoft Excel
- Git & GitHub

---

## Dataset
The dataset contains:
- Student Name
- Subject (Maths, Physics, Chemistry)
- Marks
- Result (Pass/Fail)

---

## Dashboard Features
- Bar Chart: Subject-wise performance
- Pie Chart: Pass vs Fail ratio
- Table: Detailed student data
- Slicer: Filter by student
- Cards: Total students and average marks
